## Review Focus

- Missing target or surplus takeover/return/history arguments must reject deterministically; ordinary free text and the existing command grammar retain behavior.
- An omitted epoch must neither introduce epoch0 for legacy rows nor erase a known epoch; zero is a valid first epoch but a regression from1 is rejected.
- NaN, Infinity, fractional, negative, unsafe-integer and nonnumber runtime inputs must fail before writes; failed binds must preserve the complete previous stored value.
- Replaying the same epoch must not inflate revision; advancing once must invalidate the old revision for resume while preserving WAITING_USER and exact session.
- Parser output alone grants no execution authority; existing semantic tool allowlisting/approval and all original Slack HMAC/replay/secret/thread/attention checks stay intact.
