## Outcome and approach

A local managed native Run returned from HUMAN with a current verified snapshot can commit the exact verified tree, push its actual authored SHA to its reviewed target, create/query the existing idempotent PR and finish COMPLETE/REVIEW. Human acceptance remains separate. Reuse LocalGitDelivery.commitSnapshot, the existing push command journal, selected SCM and DeliveryService; no second scheduler or Git transport.

Sending through ordinary commit/push would omit the strict proof/context owner; copying the push implementation would duplicate its receipt/recovery policy. Instead factor the existing owning push path to accept the directly required strict commit source, binding and captured environment, preserving ordinary behavior and bytes. Strict delivery remains one frozen push identity per Run/generation, as existing PR delivery; a different proof/target cannot silently reuse a prior push. Unknown effects remain barriers.
